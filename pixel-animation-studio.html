使い方と注意事項

基本操作

  1. 16×16〜128×128、またはCustomからキャンバスサイズを選びます。
  2. 鉛筆 / 消しゴム / 塗りつぶし / スポイト / 選択を使い分けます。
  3. 選択範囲は別のツールへ切り替えると解除されます。貼り付けは貼り付け先を選択してから行います。
  4. フレームを追加・複製し、サムネイルから切り替えます。

プライバシー

描画データはこのブラウザー内で処理され、このアプリから外部サーバーへ送信されません。実行時の外部通信も行いません。

v1.0.0の範囲

  • 前のフレームを約30%で重ねるOnion SkinをON/OFFできます。
  • 作業内容はIndexedDBへ端末内自動保存し、再読み込み後に復元できます。
  • PNGを1枚または複数読み込み、PNG・Animated GIF・Sprite Sheetを書き出せます。GIFは256色制約があり、半透明は透明/不透明へ変換されます。

スマートフォン

1本指で描画します。2本指でPan / Pinch Zoomできます。2本指操作へ移った場合は、誤って始まった描画を取り消して表示操作へ切り替えます。
