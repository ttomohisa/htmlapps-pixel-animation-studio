# Third-Party Notices

Pixel Animation Studio v1.0.0 has no runtime third-party dependencies declared in `dependencies.json`.

Animated GIF encoding in v1.0.0 is implemented directly in the application and does not embed a third-party GIF library.

The repository itself is based on Browser Kitty's `htmlapps-template` and retains its build, verification, and reusable component infrastructure.
